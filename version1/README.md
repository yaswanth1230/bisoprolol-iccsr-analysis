# Version 1 - Bisoprolol Adverse Reaction Analysis

## Overview

This folder contains the Version 1 documentation for the Bisoprolol Adverse Reaction Analysis project.

## Version 1 Scope

The first version of the project performs analysis of Bisoprolol adverse reaction data using Python and Pandas.

## Analysis Included

- Total number of adverse reaction cases
- Cases by age group
- Cases by gender
- Top 10 countries by number of cases
- Most common adverse reactions
- Most common serious reactions
- Case trends over time

## Visualizations

Version 1 generates the following visualizations:

1. Cases by Age Group
2. Cases by Gender
3. Top 10 Countries by Cases
4. Cases Trend Over Time

## Technologies

- Python
- Pandas
- Matplotlib
- JSON
- Excel
